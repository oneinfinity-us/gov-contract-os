# 合规注意事项（草案，需法务/业务确认）

## 抓取相关

- 抓取任何采购平台前，先确认其服务条款（ToS）/robots.txt 是否允许自动化访问；部分平台可能要求走官方 API 或注册开发者账号。
- 州/市/港务局采购规则各不相同（例如 Washington State 采购受 RCW 39 系列约束，King County、Seattle、Bellevue、Port of Seattle 各自有本地采购条例），投标资质要求需分别核实，不能假设通用。

## LLM 辅助提案生成相关

- 部分采购机构可能要求投标文件披露是否使用 AI 生成内容，或对 AI 生成内容的比例/使用方式有限制——需在起草提案前确认对应招标文件（RFP/RFQ）的具体条款。
- LLM 生成的初稿应始终经过人工审核（`src/proposal/review/`）后才提交，尤其是资质声明、报价、法律条款等关键内容不应完全依赖 LLM 输出。
- 涉及公司资质证明、财务数据等敏感信息喂给 LLM 时，注意数据隐私与模型服务商的数据使用政策。
