# Grants archive

Grants that are no longer active — closed, awarded (to someone else, or to us), or archived after a `do_not_apply` decision — move here.

Layout mirrors `opportunities/grants/inbox/`:

```
opportunities/grants/archive/<slug>/
├── manifest.yaml
├── *.pdf
└── (optional) decision-memo.md, notes.md
```

Do NOT edit the manifest after archiving — the archive is a historical record. If new information changes the decision, create a new inbox entry pointing at the archived one.
