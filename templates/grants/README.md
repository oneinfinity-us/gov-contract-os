# Grant application templates

Skeletons for the deliverables of a grant application. Phase 1 ships this directory as a placeholder — real template content lands in Phase 2 (Section 8 of `docs/architecture.md`).

Planned files:

- `letter-of-inquiry.md`
- `executive-summary.md`
- `statement-of-need.md`
- `program-description.md`
- `goals-objectives-outcomes.md`
- `work-plan.md`
- `evaluation-plan.md`
- `organizational-capacity.md`
- `sustainability-plan.md`
- `equity-and-community-engagement.md`
- `budget.csv`
- `budget-narrative.md`
- `logic-model.md`
- `theory-of-change.md`
- `application-review-checklist.md`

## Rules for future template content

Every template MUST:

1. Include a header line naming the source RFA/NOFO the section is answering.
2. Use `[HUMAN INPUT REQUIRED]` placeholders for anything that cannot be verified against the nonprofit's `organizations/<slug>/` profile.
3. Never invent participants served, outcomes, financials, board members, partner commitments, or endorsements. See [SECURITY.md](../../SECURITY.md).
